# The Next New Thing AI — Growth and Repository Research

## Scope and evidence note
Research date: 2026-10-09.

This is a source-linked first-pass review of videos whose public transcript/summary pages were discoverable in search. The channel's YouTube videos listing could not be fetched reliably in this session, so this document does **not** claim to cover every upload or every transcript on the channel. Treat video descriptions and transcript summaries as leads, not proof that a tool is safe, free, maintained, or commercially suitable. Before installation, inspect the actual upstream repository, current licence, releases, security posture and operating costs.

## Most relevant videos reviewed

### 1. [How to use OpenSEO for affordable real SEO data](https://glasp.co/youtube/UNN6dLt5dPI) — 24 Aug 2026
**Transcript/summary signal:** OpenSEO is presented as an open-source SEO research platform using data-provider inputs for keyword, competitor and backlink work, with agent coaching and customizable workflows. Provider/API costs may still apply.
**Our use:** shortlist for an SEO audit workflow, but validate its outputs against Search Console and real site data. Never let an LLM invent search volumes, backlinks or rankings. Confirm exact project identity, API costs, licence and hosting requirements.

### 2. [How to Sell 5K Month AI Agents to Businesses](https://glasp.co/youtube/FIhj0yb9KPI) — 19 Aug 2026
**Transcript/summary signal:** sell a business outcome and ongoing operational value rather than a bundle of tokens or a list of agents; demonstrate a real workflow, then retain clients through measurable improvements and regular reviews.
**Our use:** do not copy the advertised $5,000/month figure as a price promise. Start with a tightly scoped paid pilot, record baseline and post-delivery results, then offer a retainer only where ongoing value and support costs justify it.

### 3. [How to Run a Business with Claude Code for AI Agents](https://glasp.co/youtube/F-_q6VIHMS8) — 1 Sep 2026
**Transcript/summary signal:** shared context, connected business tools, GitHub as a durable memory, PostHog for conversion measurement, content-to-lead-magnet funnels, landing pages, and automated checks with browser testing and error monitoring.
**Our use:** create one auditable operating system: versioned docs + GitHub task/decision records + analytics events + reviewed content and experiments. Keep data access least-privileged; no agent should have unrestricted access to every business system.

### 4. [How to find local clients with Hyper Agent?](https://glasp.co/youtube/pIyqwrZ0x8Y) — 12 Aug 2026
**Transcript/summary signal:** a prospecting loop identifies local firms with strong reputation but weak websites, drafts tailored examples, tracks leads in a CRM and uses a demonstration to start sales conversations.
**Our use:** a useful service-acquisition hypothesis. Do not mass-scrape personal data or automatically send unsolicited bulk messages. Manually validate a small list, personalize contact, respect consent and opt-outs, and track qualified replies, proposals, paid conversions and margin. Any free sample must be bounded and not alter a customer's live site without permission.

### 5. [How to use Buzz for AI agent teamwork and coding?](https://glasp.co/youtube/W0r8xrWIYGw) — 29 Jul 2026
**Transcript/summary signal:** a shared collaboration surface may bring humans and multiple agent runtimes into one workspace.
**Our use:** evaluate only if our current GitHub + project docs + task tracker cannot provide adequate coordination. Avoid adopting another control plane before measuring a concrete coordination gap.

### 6. [How to use free AI agents and second brains effectively](https://glasp.co/youtube/PdM8YNuLEgc) — 20 Aug 2026
**Transcript/summary signal:** specialized agents and personal knowledge systems can help organize activity and reduce repeated context gathering; local-first approaches can improve data control.
**Our use:** store durable project facts, decisions and outcomes in versioned project docs. Keep a private founder diary outside shared/public repositories and never index personal files or customer data without explicit authorization.

### 7. [How to make AI coding simpler and more reliable](https://glasp.co/youtube/aX8Y183qDpY) — 11 Sep 2026
**Transcript/summary signal:** concise instructions, explicit plans, small changes, tests, reviews and reusable skills improve coding reliability; architecture visualization and context-control tools may help.
**Our use:** standard task contracts, narrow PRs, acceptance criteria, independent review and evidence-based completion. A tool or agent's confidence is not a substitute for passing tests and human approval.

### 8. [How to replace QuickBooks with Slowbooks open source](https://glasp.co/youtube/-ikuVZ9L-UE) — 8 Sep 2026
**Transcript/summary signal:** an AI-assisted accounting project emphasizes import/export, receipt OCR, double-entry records, local operation and an audit trail.
**Our use:** research only. Verify the canonical upstream repository before any use. Never let an agent finalize tax, payroll or accounting judgments without qualified human review and reconciliation.

### 9. [Which GitHub Repositories Help Build AI Tools?](https://glasp.co/youtube/TWCSvvTfJNU) — 28 Aug 2026
**Transcript/summary signal:** broad developer-tool survey including plugins, local agent workflows, video and coding resources.
**Our use:** repository discovery should feed the same small pilot process; do not install a tool just because it is featured or trending.

### 10. [How to find top AI GitHub repos for diagrams and agents](https://glasp.co/youtube/SQrFue3LbwI) — 21 Aug 2026
**Transcript/summary signal:** visual diagrams, context organization, knowledge graphs, local models, model routing and video automation are recurring themes.
**Our use:** test codebase context tools against a known question and measure accuracy, time, token usage and setup/maintenance burden. Keep diagram generation as documentation support, not a substitute for architecture review.

### 11. [What are the top GitHub repos for AI projects this week](https://glasp.co/youtube/AWzzmrCPe-A) — 4 Sep 2026
**Transcript/summary signal:** architecture diagrams and other specialized projects are highlighted as ways to make complex systems easier to understand and operate.
**Our use:** prioritize clear system maps, onboarding docs and a small number of reusable tools over novelty-driven installation.

### 12. [Top free self-hosted AI tools for video and coding](https://glasp.co/youtube/3Cni6_JubQk) — 26 Jun 2026
**Transcript/summary signal:** OpenMontage for agent-assisted video production and codebase-memory-MCP for code context appear as possible building blocks; the episode also discusses local/self-hosted creator tools.
**Our use:** consider OpenMontage later for original marketing content, subject to licensing and media rights. Consider codebase-memory-MCP for developer productivity after a disposable-clone security review.

### 13. [10 GitHub Repos That Will Kill Your Monthly Subscriptions](https://invidious.thehtmlproject.com/watch?listen=false&v=jMAe1h39rHo) — 11 Aug 2026
**Transcript/summary signal:** AppFlowy, Immich, Documenso, Excalidraw, Penpot, Cal.diy, Listmonk, Dub, RustDesk and FluidVoice are discussed as alternatives to paid tools.
**Our use:** Cal.diy is relevant to booking; Listmonk may be worth evaluating for opt-in newsletters; Penpot/Excalidraw for design/diagrams. Defer unrelated personal photo, remote desktop and office-productivity infrastructure unless a clear need appears. Self-hosting shifts costs to maintenance and security.

## Growth principles distilled from these sources
1. Sell the measurable business outcome, not the number of agents or a flashy tool demo.
2. Build a single verticalized offer first; keep the scope narrow and record the before/after result.
3. Connect acquisition → lead capture → follow-up → booking → delivery → invoice → retention → analytics, but introduce one integration at a time.
4. Keep shared project context in versioned documents; keep private founder notes and customer secrets out of public repos.
5. Use real source data for SEO and market research; distinguish observed facts, estimates and model-generated hypotheses.
6. Treat every open-source project as a candidate: check licence, security, maintenance, data flow, dependencies, hosting and removal path.
7. Automate internal delivery only after the manual workflow succeeds; then package it as a repeatable service and later as software.
8. Measure paid conversion, gross margin, delivery hours, support burden, qualified leads and real user outcomes. Do not scale vanity metrics.
9. Keep human approval for production changes, public publishing, financial decisions, external outreach, sensitive data and permission changes.
10. Do not install the whole list. Run small, reversible evaluations and adopt only the tools that beat the current baseline.

## Recommended next evaluation order
1. Review existing analytics; test PostHog only if the current stack lacks required funnel/experiment visibility.
2. Test OpenSEO against one site using real, authorized data and independently verify its recommendations.
3. Trial Marketing Skills and Last30Days on one growth question, tracking factuality and time saved.

5. Choose at most one CRM/support/intake system after mapping the current lead lifecycle.
6. Defer billing, newsletter and video-production infrastructure until a live customer/product workflow requires them.
