A transcript mention does not prove the canonical GitHub URL, current licence, or suitability for commercial use. Before adoption, inspect the original video description and upstream repository.

## Income-oriented prioritization

1. **Measure and improve an existing funnel:** PostHog only if current analytics are insufficient; run one controlled audit and prove the result.
2. **Find qualified customer problems:** OpenSEO and research tools against one real question, using source-backed facts and explicit data/API costs.
3. **Deliver a bounded service:** use the evidence to offer a local-business visibility/enquiry improvement pilot; keep prospect research and messages manually reviewed.
4. **Reduce delivery cost:** test one engineering or context tool on a disposable clone, comparing time, defects, model cost and reviewer effort.
5. **Add operational systems only when needed:** choose one CRM, support inbox, scheduling and invoicing workflow only after mapping what already exists.
6. **Content/product experiments later:** test one rights-cleared media asset or pre-sold digital template only when an audience and buyer problem are clear.
